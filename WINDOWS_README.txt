TryLedger - Windows Desktop Application

INSTALLATION INSTRUCTIONS:
1. Extract the contents of TryLedger_Windows_v1.0.0.zip to any folder on your Windows computer
2. Run tryledger.exe to start the application
3. The application will create its database automatically on first run

- Windows 10 or higher (64-bit)
- No additional dependencies required
